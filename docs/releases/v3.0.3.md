## Highlights

- **Single-file downloads.** The Windows, Linux and macOS engines are now one
  executable each, with the network, ONNX Runtime and the license texts
  built in. Download it, verify the checksum and run it; there is nothing to
  extract or install, and Windows no longer needs the Visual C++
  Redistributable. `--licenses` prints the licenses of Hivemind and the
  software it includes (#65).
- The engine uses its built-in network unless `--model` names another one.
- Same engine and network as v3.0.2 (twin-s-clock RL iteration 10).
- The superseded `rl_loop.sh` script is removed; use `hivemind rl-loop` (#64).

## Downloads

| Computer | Download | Size |
|---|---|---|
| Windows x86-64 — easiest start | `hivemind-v3.0.3-windows-x86_64.exe` | 23 MB |
| Linux x86-64 (Ubuntu 24.04+, glibc 2.39+) | `hivemind-v3.0.3-linux-x86_64` | 33 MB |
| Apple silicon, macOS 14+, Core ML | `hivemind-v3.0.3-macos-arm64` | 22 MB |
| Windows x86-64, NVIDIA GPU | `hivemind-v3.0.3-windows-x86_64-tensorrt.zip` | About 2 GB |
| Linux x86-64, NVIDIA GPU | `hivemind-v3.0.3-linux-x86_64-tensorrt.zip` | About 2 GB |

Download the file for your computer and its `.sha256` file and verify it. On
Linux and macOS, browsers drop the executable bit: run `chmod +x` on the file
once. Select the executable in a bughouse-compatible GUI; it speaks UCI.

The NVIDIA downloads are ZIP bundles as before: extract the whole ZIP and use
`bin\hivemind.exe` (Windows) or the top-level `hivemind` launcher (Linux).
They require Turing or newer hardware (compute capability 7.5+, such as RTX
20 series and newer) and driver R580+; R610+ is recommended for the bundled
CUDA 13.3 runtime. **First launch takes several minutes** to build a
GPU-specific cache. Windows NVIDIA bundles need the Visual C++ x64
Redistributable.

The macOS download is **unsigned and not notarized**. After verifying it,
run `xattr -d com.apple.quarantine hivemind-v3.0.3-macos-arm64` if macOS
blocks it. See the [download and compatibility guide](https://github.com/aminwoo/hivemind/blob/v3.0.3/docs/distribution.md)
for checksum commands and troubleshooting.

## Validation

- Release CI verifies the pinned network checksum and runs each single
  executable alone in an empty directory on Ubuntu 24.04, Windows Server
  2022 and macOS 14 arm64 (CPU mode): `--licenses` and two 200-node searches
  on the built-in network.
- TensorRT CI validates startup, archive integrity, and checksums.
- The downloads were not run on physical GPUs for this release: NVIDIA
  inference and macOS Core ML / Neural Engine are unvalidated. Hosted macOS
  CPU checks do not validate ANE.
