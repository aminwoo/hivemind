## Highlights

- Fixes a false losing evaluation when a timed or stopped search ends before
  its reported move has any visits (#49). It reports the root's value instead
  of an uninitialized edge value.
- Adds live MultiPV reports, charges the searched move its clock budget, and
  improves search batching and PUCT widening since v3.0.0.
- Restores compatibility with macOS 14 build tools that lack floating-point
  atomic `fetch_add`, while retaining native atomic addition where available.
- Adds a direct download guide, explicit compatibility requirements, NVIDIA
  first-launch guidance, and verified source downloads for twin-s-clock.
- Strengthens release validation with checksum verification, protocol
  handshakes, two completed searches, provider checks, and draft staging for
  physical hardware checks.

## Downloads

The engine, twin-s-clock RL iteration 3 network, and runtime are bundled.
Download the matching ZIP and checksum, verify it, then extract everything.
No Python or separate model download is needed.

| Computer | Bundle | Approximate ZIP size |
|---|---|---|
| Windows x86-64, CPU — easiest start | `hivemind-v3.0.1-windows-x86_64-onnxruntime.zip` | 9 MB |
| Ubuntu 24.04+ x86-64, CPU — easiest start | `hivemind-v3.0.1-linux-x86_64-onnxruntime.zip` | 15 MB |
| Apple silicon, macOS 14+, Core ML | `hivemind-v3.0.1-macos-arm64-onnxruntime.zip` | 15 MB |
| Windows x86-64, NVIDIA GPU | `hivemind-v3.0.1-windows-x86_64-tensorrt.zip` | About 2 GB |
| Ubuntu 24.04+ x86-64, NVIDIA GPU | `hivemind-v3.0.1-linux-x86_64-tensorrt.zip` | About 2 GB |

Select `bin\hivemind.exe` (Windows) or the top-level `hivemind` launcher
(Linux/macOS) in a bughouse-compatible GUI. The network is found automatically.

NVIDIA bundles require Turing or newer hardware (compute capability 7.5+,
such as RTX 20 series and newer) and driver R580+; R610+ is recommended for
the bundled CUDA 13.3 runtime. CUDA and TensorRT do not need installing.
**First launch takes several minutes** to build a GPU-specific cache. Allow
at least 6 GB free space. Windows also needs the Visual C++ x64 Redistributable.

The macOS bundle is **unsigned and not notarized**. After verifying the ZIP,
run `xattr -dr com.apple.quarantine .` inside the extracted folder if macOS
blocks it. See the [download and compatibility guide](https://github.com/aminwoo/hivemind/blob/v3.0.1/docs/distribution.md)
for checksum commands and troubleshooting.

## Validation

- Engine regression suite: 451 passed, one existing test skipped. One
  timing-sensitive mate test failed under parallel load, then passed three
  consecutive isolated reruns. Native and fallback atomic-add paths also
  passed a standalone concurrent-update check.
- Release CI verifies the pinned network checksum and runs two 200-node
  searches from each portable ZIP on Ubuntu 24.04, Windows Server 2022,
  and macOS 14 arm64 (CPU mode).
- TensorRT CI validates startup, archive integrity, and checksums.
- Physical NVIDIA validation is recorded below before publication.
- Physical macOS Core ML / Neural Engine and Windows NVIDIA inference have
  not been validated for this release. Hosted macOS CPU checks do not validate ANE.
