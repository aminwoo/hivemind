## Highlights

- Bundles **twin-s-clock RL iteration 10**, the newest clock-aware network.
  It beat the previous generator 520-479-1 on the clock at 100 ms per move
  (+14 Elo).
- Core ML now runs on the Neural Engine by default on Apple silicon, and the
  default network is converted for Core ML on first launch.
- Mate search: reports a tree-proven loss in the team's own moves (#50),
  reports where each search's mates came from (#51), adds an exhaustive
  offline mate oracle (#52), and shares one direct-threat proof across quiet
  root defenses (#53).
- Search fixes: background search judges the reused tree for our own team
  (#56), and concurrent backups on a new edge are all counted (#57).
- Self-play reuses the played move's subtree for the same team and resumes
  interrupted runs (#54, #55).
- Repository and documentation cleanup (#58, #59).

## Downloads

The engine, twin-s-clock RL iteration 10 network, and runtime are bundled.
Download the matching ZIP and checksum, verify it, then extract everything.
No Python or separate model download is needed.

| Computer | Bundle | Approximate ZIP size |
|---|---|---|
| Windows x86-64, CPU — easiest start | `hivemind-v3.0.2-windows-x86_64-onnxruntime.zip` | 9 MB |
| Ubuntu 24.04+ x86-64, CPU — easiest start | `hivemind-v3.0.2-linux-x86_64-onnxruntime.zip` | 15 MB |
| Apple silicon, macOS 14+, Core ML | `hivemind-v3.0.2-macos-arm64-onnxruntime.zip` | 15 MB |
| Windows x86-64, NVIDIA GPU | `hivemind-v3.0.2-windows-x86_64-tensorrt.zip` | About 2 GB |
| Ubuntu 24.04+ x86-64, NVIDIA GPU | `hivemind-v3.0.2-linux-x86_64-tensorrt.zip` | About 2 GB |

Select `bin\hivemind.exe` (Windows) or the top-level `hivemind` launcher
(Linux/macOS) in a bughouse-compatible GUI. The network is found automatically.

NVIDIA bundles require Turing or newer hardware (compute capability 7.5+,
such as RTX 20 series and newer) and driver R580+; R610+ is recommended for
the bundled CUDA 13.3 runtime. CUDA and TensorRT do not need installing.
**First launch takes several minutes** to build a GPU-specific cache. Allow
at least 6 GB free space. Windows also needs the Visual C++ x64 Redistributable.

The macOS bundle is **unsigned and not notarized**. After verifying the ZIP,
run `xattr -dr com.apple.quarantine .` inside the extracted folder if macOS
blocks it. See the [download and compatibility guide](https://github.com/aminwoo/hivemind/blob/v3.0.2/docs/distribution.md)
for checksum commands and troubleshooting.

## Validation

- Release CI verifies the pinned network checksum and runs two 200-node
  searches from each portable ZIP on Ubuntu 24.04, Windows Server 2022,
  and macOS 14 arm64 (CPU mode).
- TensorRT CI validates startup, archive integrity, and checksums.
- Physical NVIDIA validation is recorded below before publication.
- Physical macOS Core ML / Neural Engine and Windows NVIDIA inference have
  not been validated for this release. Hosted macOS CPU checks do not validate ANE.
